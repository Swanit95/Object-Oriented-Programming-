# Assignment 03 - Operator Overloading

Practical No.: 03  
Practical Title: OPERATOR OVERLOADING  
Programming Language: C++

This assignment demonstrates operator overloading in C++ using a real-world travel-time example. A `Time` class stores hours and minutes, provides default and parameterized constructors, and overloads the `+` operator to add a travel duration in minutes to a departure time.
